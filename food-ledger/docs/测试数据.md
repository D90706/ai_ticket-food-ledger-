# 测试数据

给手工测试用的现成数据：能直接粘贴的对话文本、手填对照表、批量造数据的脚本。

## 一、先说一个容易误判的现象

如果 AI 回你：

> 还需要确认：名称、规格、数量、单位、生产日期、生产批号、保质期、进货日期、
> 供货者名称、供货者地址、联系方式、索证索票凭证（共 12 项）。

**十二项全缺**，说明这次**一个字都没抽到**，只有两种原因：

| 原因 | 怎么确认 |
|---|---|
| 你发的那句话里没有采购信息（比如「土豆」「帮我记一下」） | 这是正常的：模型没东西可抽，只能问你要 |
| 模型输出无法解析，本次降级成空 | 后端日志里会有 `抽取降级：两次都没能拿到可用 JSON` |

正常的采购描述，哪怕很短（「老张送了一箱土豆」），也至少能抽出名称、数量、单位。
所以看到"缺 12 项"时，先看日志有没有「抽取降级」，再检查输入内容。

## 三、手填对照表（19 个字段填什么）

「审批/测试」时照这张表填，两分钟一条。

| 字段 | 分类 | 示例值 | 说明 |
|---|---|---|---|
| 名称 | 法定·必填 | 冷鲜猪肉 | 食材通用名，不要写商品名 |
| 规格 | 法定·必填 | 散装 / 25kg/袋 | 包装或形态 |
| 数量 | 法定·必填 | 20 | 纯数字，单位另填 |
| 单位 | 法定·必填 | 斤 | 下拉：斤/公斤/箱/袋/瓶/桶/包 |
| 生产日期 | 法定·必填 | 2026-10-26 | 生产当天或包装日期 |
| 生产批号 | 法定·必填 | R20261026-3 | 包装上的批号；散装无批号就填生产日期 |
| 保质期 | 法定·必填 | 冷藏3天 / 180天 | 按包装写，别自己折算 |
| 进货日期 | 法定·必填 | 2026-10-28 | 默认今天 |
| 供货者名称 | 法定·必填 | 城南肉联厂 | 与证照上的主体一致 |
| 供货者地址 | 法定·必填 | 城南大道88号 | 与证照一致 |
| 联系方式 | 法定·必填 | 13800001111 | 供货者联系电话 |
| 索证索票凭证 | 法定·必填 | SC-2026-A-1234 | **可以直接上传照片，不用填编号** |
| 到期日 | 选填 | 2026-10-29 | 填了才有临期/过期预警 |
| 品类 | 选填 | 肉类 | 决定品类筛选与统计；按品名判断 |
| 单价 | 选填 | 28.5 | 填了会自动算金额 |
| 金额 | 选填 | （自动） | 数量 × 单价，不用填 |
| 入库仓库 | 选填 | 一号冷库 | |
| 验收人 | 选填 | 李采购 | |
| 产地 | 选填 | 本地 | |
| 冷链到货温度 | 选填 | 4 | 冷藏/冷冻食材填 |
| 农残检测报告号 | 选填 | NY-2026-110 | 蔬菜类填 |

> 12 项法定项目缺任何一项 → 判「不合规」，不能入账。
> 选填项缺 → 判「待补证」，可以入账但要补。

## 四、批量造演示数据

空库点不出效果：筛选筛不出东西、统计全是 0、导出一张空表。用脚本一次造 30 条：

```bash
# 后端已启动
python qa/seed-demo-data.py
```

它会生成 30 条以 `DEMO-` 开头的记录，并刻意造成这些分布：

| 维度 | 覆盖 |
|---|---|
| 时间 | 跨 3 个月（今天往前 82 天到当天） |
| 品类 | 肉类 / 蔬菜 / 水产 / 粮油 / 蛋奶 |
| 供货者 | 5 家，其中 1 家证照 12 天后到期、1 家已过期 |
| 状态 | 待入账 14 / 已入账 13 / 退回补录 2 / 已作废 1 |
| 到期 | 含已过期与 2 天内到期的记录 |

清理：

```bash
python qa/seed-demo-data.py --clean     # 把 DEMO- 开头的记录全部作废
```

台账不允许物理删除，所以"清理"是作废而不是删除——已作废的记录不计入统计。

## 五、这些数据能验证什么

| 想验证的功能 | 用哪批数据 |
|---|---|
| AI 能一次说全就出单 | 第二节 6 条文本 |
| 绿色（记录完整）状态 | 第 7 条完整版 |
| 红色（不合规）拦截 | 手填只填名称就提交 |
| 临期/过期提示 | 第 4 条（到期日已过）、seed 脚本里最近三天的记录 |
| 品类筛选 | seed 脚本造的 5 个品类 |
| 状态流转 | seed 脚本的四种状态各若干条 |
| 统计口径 | seed 脚本（含已作废，用于验证"总金额不含作废"） |
| 导出完整性 | seed 脚本 + 先筛「不合规」再导出 |
| 证照预警 | seed 脚本造的 5 家供应商（1 临期、1 过期） |

## 六、相关脚本

| 脚本 | 用途 |
|---|---|
| `qa/verify-dialogue-samples.py` | 验证第二节的文本是否真能一次说全（会真的调模型） |
| `qa/seed-demo-data.py` | 批量造/清演示数据 |
